# edcs/homebrew-tap

Homebrew casks for my apps.

```sh
brew install --cask edcs/tap/ipbar
```

## What's here

| Cask | What it is |
| --- | --- |
| [`ipbar`](https://github.com/edcs/ipbar) | A macOS menu bar app that shows your IP address, and lets you give addresses names |

Casks in this repo are written by CI. Releasing [ipbar](https://github.com/edcs/ipbar)
updates `Casks/ipbar.rb` here with the new version and checksum, so nothing in this repo
needs editing by hand.
